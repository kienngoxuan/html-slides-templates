Lecta AI — Extended Specification

Ideas and features not explicitly mentioned in the user requirements but highly valuable for the product vision.

1. Future Block Types

Image + Hotspot Block Idea High Priority

An image with clickable regions (hotspots). Each hotspot opens a tooltip or popup with explanatory text. Ideal for anatomy diagrams, architecture diagrams, and UI walkthroughs.

  • JSON schema: { "type": "hotspot", "image": "SAMPLE_PICTURE", "spots": [{ "x": 30, "y": 50, "label": "...", "detail": "..." }] }
  • CSS: absolute-positioned dots on a relative container, with tooltip on click

Code Playground Block Idea Medium Priority

Embedded editable code editor with live preview (like CodePen). Uses a <textarea> + <iframe> for HTML/CSS demos. No external dependencies needed.

Branching / Decision Tree Block Idea Medium Priority

User selects Option A or B, which navigates to different follow-up content. Useful for case studies, "choose your own adventure" learning, and debugging exercises.

Drag-and-Drop Sorting Block Idea Low Priority

Students reorder items (e.g., steps in a process) to test comprehension. Uses HTML5 drag events — no library needed.

Fill-in-the-Blank Block Idea Medium Priority

Sentence with blanks that students type into. Instant feedback on submit. Good for vocabulary and concept reinforcement.

2. AI Enhancement Ideas

Automatic Difficulty Scaling AI High Priority

Given a slide deck, generate 3 variants: beginner (simple language, more visuals), intermediate (standard), advanced (technical depth, fewer explanations). The JSON structure stays the same — only content depth changes.

Auto-Detect Slide Issues AI High Priority

AI scans each slide and flags: too much text (>150 words), no visual elements, no interactivity, missing speaker notes, duplicated content between slides.

Tone Adaptation AI Medium Priority

Transform the same content into different voices: academic, casual, corporate, playful. Especially useful when the same material is presented to different audiences.

Smart Slide Splitting AI Medium Priority

When a slide has too many bullet points or concepts, AI suggests splitting it into 2-3 slides with smooth transitions and connecting phrases.

3. UX Improvements

Slide Minimap / Outline Sidebar UX High Priority

A collapsible left sidebar showing thumbnail previews of all slides. Clicking a thumbnail jumps to that slide. Keyboard shortcut: Ctrl+M.

Keyboard Shortcut Overlay UX Low Priority

Press ? to show a modal listing all keyboard shortcuts. Common in presentation tools.

Fullscreen Mode UX High Priority

A button to enter browser fullscreen (document.documentElement.requestFullscreen()). Hides browser chrome for a cleaner presentation experience.

Print-Optimized CSS UX Medium Priority

A @media print stylesheet that renders each slide on a separate page, hides navigation, and expands all accordion/tab content for a complete printout.

Slide Transition Animations UX Low Priority

Beyond the current horizontal slide, add options: fade, zoom, flip, cube rotation. Configurable per-slide or globally in the JSON meta.

4. Export & Integration

JSON Import/Export Export High Priority

A button in the presentation that downloads the slide data as JSON. Another tool/page that imports JSON and re-renders. This enables sharing, version control, and AI-based editing workflows.

Embed Mode (iframe-friendly) Export Medium Priority

A URL parameter ?embed=true that hides the nav bar, theme switcher, and speaker notes — making the deck embeddable in LMS platforms, blogs, and documentation sites.

QR Code Slide Idea Low Priority

Auto-generate a QR code on the last slide linking to the hosted version, so audience members can access the deck on their phones immediately.

5. Teacher-First Features

Hidden Teacher Notes Layer UX High Priority

Beyond speaker notes, a "teacher-only" layer with: timing suggestions, common student questions, answer keys, and follow-up prompts. Toggled with a password or button combination.

Auto-Generated Recap Slide AI Medium Priority

At the end of a deck, automatically generate a "What We Covered" slide by extracting headings from all previous slides.

Random Student Selector Idea Low Priority

A widget in presenter mode that randomly picks a student name from a pre-loaded list. Fun for participation and engagement.

Lesson Timer with Pacing Alerts UX Medium Priority

Set expected time per slide. Timer changes color when you're behind schedule. Helps teachers stay on track during live sessions.

6. Design System Notes

Why OKLCH Colors

  • Perceptual uniformity: Equal lightness values actually look equally bright (unlike HSL)
  • Predictable palettes: Changing hue while keeping L and C constant produces harmonious variants
  • Wide gamut: Access to colors beyond sRGB on modern displays
  • CSS-native: Supported in all modern browsers since 2023

3-Layer Token Architecture

  • Base tokens: Raw OKLCH values (oklch(55% 0.12 250))
  • Semantic tokens: --color-primary, --color-success, --color-bg
  • Component tokens: --btn-bg, --card-border (not yet implemented, planned)

Responsive Strategy

  • Slides use clamp() for fluid typography
  • Block layouts switch from multi-column to single column at 768px
  • Touch swipe enabled for mobile navigation
  • Nav bar fixed at bottom for thumb-friendly mobile use
